# Folio Android annotation and storage build — verification

## Implemented in the current source

- Android Save As and Share stage an annotated PDF privately, validate it, and use SAF/chooser with a read-only share provider. Source PDFs are not overwritten.
- Folio highlights, underlines, strikeouts, notes, ink, boxes, ellipses, lines and arrows export with visible PDF annotation appearances. Text exports visibly in English; Bengali and mixed Bengali/English are shaped with HarfBuzz and the bundled OFL-licensed Noto Sans Bengali, then outlined in the annotation appearance with Unicode `/Contents`. A missing script font is an explicit export error. Newly authored visible text uses a PDF Stamp appearance, **not** a mislabeled FreeText subtype; outlined glyphs are not selectable as font text.
- Third-party **single-quad, axis-aligned highlights/underlines/strikeouts, sticky notes, squares and circles** can be selected from the PDF or Notes. Selection converts that original into an editable Folio overlay, with the original suppressed only in the viewer's in-memory PDF. Colour, size/position where not text-anchored, comment and deletion persist in a versioned sidecar and work with undo/redo. Save As validates the original subtype **and fingerprint** before replacing exactly that annotation in the exported copy. Tombstones remove deleted imports without losing the original PDF. Multi-quad/angled markup and other unsupported PDF annotation types remain untouched and are identified as preserved, not silently replaced.
- Notes indexes imported metadata lazily. Folio layer switches are functional; PDF optional-content groups remain **read-only**, per the agreed scope. Page rotation changes only the view and its geometry, not `/Rotate` in the source PDF.
- Compact Home Settings offers appearance, density, default **Keep offline copy** versus validated source-only for new Android imports, and a per-document storage picker. Home cards respond to 0.5-second touch hold and desktop right-click with Open, Keep offline copy, Use source only, Relink source PDF, and Remove from library. Unavailable linked items remain in recents with their Folio sidecars. Android source-only requires a persisted per-file SAF grant, seekable regular FD, PDFium reopen and exact SHA-256 match before removing an offline copy; relink requires an exact match. Provider or grant failure leaves a private copy where available. See `docs/PDF-STORAGE-MODES-DESIGN.md`.
