Folio - Windows build
=====================

Contents
    Folio.exe      the application
    pdfium.dll     the PDF engine; must stay beside Folio.exe
    assets\        fonts and icons; must stay beside Folio.exe
    documents\     sample PDFs

Running
    Extract the WHOLE ZIP into a folder, then double-click Folio.exe there.
    Do not move Folio.exe alone to Pictures/Desktop: pdfium.dll and assets\fonts
    must remain beside it. The integrated title bar starts maximised inside
    the monitor work area (the taskbar stays visible); Restore returns to a
    centred, resizable window. Drag its empty title bar/wordmark to move it;
    double-click there to toggle maximisation.

Troubleshooting an access violation
    Run Folio.exe --software from PowerShell in the extracted ZIP folder. If
    only the GPU version crashes, report that difference and your graphics
    driver model. Folio attempts to save a local crash minidump under
    %LOCALAPPDATA%\Folio\crashes\ on Windows. Dumps can include PDF text:
    do not post one publicly; share privately only if you choose. Send the
    exception code and whether --software also crashes. A passing CI test
    suite cannot prove that a particular graphics driver/PDF will not crash.

If SmartScreen blocks it
    The binary is unsigned, so "Windows protected your PC" is expected.
    More info -> Run anyway. Code signing needs a certificate, which is a
    purchase decision, not a build setting.

Known limitations in this build
    - The Win32 window backend is new. If the window misbehaves, run with
      --software to bypass the GPU path.
    - PoDoFo is off in the supported Windows build (-DFOLIO_WITH_PODOFO=OFF).
      Save makes a separate annotated PDF via PDFium (highlights,
      underlines, strikeouts, ink, notes, boxes and ellipses).
      Free text, stamps and signatures are refused rather than dropped.
      Save As does not rewrite the original; page-tree edits still need
      PoDoFo. Folio annotations persist in the private app-state sidecar even
      if no exported PDF has been created. Desktop opens the ORIGINAL PDF
      path and does not automatically keep a second offline PDF copy.
